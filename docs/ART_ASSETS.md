# Game artwork inventory

All packages are original Quiet Arcade work. Raster covers are reproducible with `npm run art:memory`, `npm run art:word`, `npm run art:color`, and `npm run art:shattered`; gameplay screenshots are captures of the actual game DOM. JPEG social cards are used for Open Graph, Twitter, and structured data.
