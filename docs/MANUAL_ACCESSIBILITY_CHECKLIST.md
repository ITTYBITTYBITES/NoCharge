# Manual accessibility checklist

This document records accessibility verification that automated tooling cannot
complete on its own. It does not claim certification. An item is marked complete
only when a real person has performed the check and recorded a result.

## 1. Automated checks completed

Automated checks run in the repository suite and cover the public pages,
including `/accessibility/`.

- [x] Axe automated scan against public pages and games (no detectable violations)
- [x] Single H1 per page, canonical URLs, and logical heading structure
- [x] HTML validation, internal-link checks, sitemap validation, and asset budgets
- [x] Consent-gated network checks (no optional third-party request before consent)

Automated checks reduce risk but do not prove assistive-technology compatibility.
