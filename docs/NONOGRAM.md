# Nonogram / Picross

## Rules

5×5 and 10×10 grids with row/column clues. Mark cells as filled, empty, or unknown. Solved when grid matches the hidden picture.

## Curated Puzzle Library

24 puzzles total: 12 at 5×5, 12 at 10×10. Themes: animals, food, shapes, objects.

Every puzzle has been validated to have a unique solution.

## My Arcade Keys

| Key | Description |
|-----|-------------|
| `nocharge:nonogram:puzzles-revealed` | Count of completed puzzles |

## Accessibility

- "Show clues as text" button: full text listing of every row/column clue.
- Arrow keys move cursor; F marks filled, X/Space marks empty, U undoes.
- No fail state, no timer, no streak.
- Clues dim when satisfied.

## Solver Validation

Each puzzle in the library has exactly one solution that satisfies all clues. This means no guessing is required — every cell can be determined by logic.
