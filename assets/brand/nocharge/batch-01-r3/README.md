# NoCharge Batch 01 replacement · R3

A review-only batch of exactly ten supplemental category/section SVG icons based on a direct audit of the live `https://nocharge.net/` identity. This is **not** a new wordmark, logo, favicon, social image, cover-art set, or independent visual identity.

## Contents

- `source/` — ten original editable SVG icons.
- `optimized/` — ten losslessly minified SVG copies; these are derivatives, not additional designs.
- `review/contact-sheet.png` — ten-icon contact sheet.
- `review/individual-previews.html` — offline-friendly, responsive individual previews.
- `review/design-proposal.md` — rationale for each item and how it matches the live site.
- `review/website-visual-audit.md` — rendered desktop/mobile audit, live palette, typography, logo, icons, cards, and existing assets.
- `review/reference/` — screenshots of the live site used in the visual audit; not proposed artwork.
- Asset manifest: `../../../manifest.csv`.

All R3 assets are awaiting explicit review. None is approved or integrated. The original R1 and R2 packages remain preserved in their separate folders; their artwork was not reused.
