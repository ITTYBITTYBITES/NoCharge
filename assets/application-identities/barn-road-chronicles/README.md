# Barn Road Chronicles: Act 1 — isolated artwork archive

This directory contains a clean-room set of original SVG illustrations authored for NOCHARGE V2 Phase 5B-3 on 2026-11-16. The images are new NoCharge concept drawings, not copies, traces, crops, color edits, or derivatives of the itch.io listing, its screenshots, title treatment, icons, or promotional art.

## Factual review and attribution

- **Primary factual reference:** ITTYBITTYBITES’ Barn Road Chronicles: Act 1 listing — <https://ittybittybites.itch.io/barn-road-chronicles-act-1/>. Listing details were used only for attributed copy about the creator-hosted prototype; its prose and visual media were not reused.
- **Art attribution:** Original vector drawings created for this project. No outside artist, image, icon pack, logo, font file, raster reference, or listing artwork is included. The manifest records each source and lossless derivative under an `NC-BRC-*` ID.
- **Archived concept:** The scene, emblem, and evidence drawings were authored for an earlier local-vignette concept. They are not a verified reproduction of the itch.io game and are not shown on the current NoCharge route.
- **Scope:** `/experiences/barn-road-chronicles/` only. Attribution and audit only; these assets are not shared NoCharge branding, Experience-directory product art, Arcade art, Tool art, or Shop assets.
- **Current integration:** None. BRC remains an itch.io-only static outbound showcase. Its direct player URL and framing policy are unverified, so the NoCharge route does not embed itch.io, load game assets, or publish a local player/demo. The orphaned preview component and runtime identity registry have been removed; no published Experience entry imports these illustrations.
- **Technical notes:** The SVG files use theme/event tokens and contain no linked resources, scripts, raster images, external fonts, or network URLs. Source and optimized files remain only in this attribution archive and canonical manifest; they are not imported, bundled, or rendered by the current site.
