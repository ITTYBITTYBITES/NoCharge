Two additions are live. The first is [site search](/search/): a search field in the site header and on the 404 page looks across every game, guide, article, tool, setup note, collection, and main page. The index is a small static JSON file built with the site, so queries are matched entirely in your browser — nothing you type is sent to a server — and searches are shareable with a `?q=` link.

The second replaces the ambient mixer's older noise-focused options with [ten calm procedural soundscapes](/tools/ambient-mixer/): six nature scenes (meadow morning, mountain stream, zen garden, ocean shore, pine forest, summer night) and four calm music beds (floating pads, kalimba lullaby, singing bowls, music box drift). Every soundscape is still generated live with the Web Audio API — no recordings, no loops — and saved ambient choices migrate automatically to the closest new soundscape.
