NoCharge now has a deliberately constructed brand symbol — four rounded tiles with an open doorway — replacing the provisional letter mark. The package includes full favicon and PWA icon sets, dark and light lockups, monochrome variants, a default social card, and a public `/media/` page with accurate facts, selected game assets, and a reproducible media kit. A general site feed (`/feed.xml`) publishes meaningful platform updates alongside the existing Quiet Setup feed.
