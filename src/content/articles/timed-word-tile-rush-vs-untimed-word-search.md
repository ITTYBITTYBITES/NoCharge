**Bottom line:** Word Tile Rush is NoCharge's one timed word game — letters rise and you spell adjacent words before the grid fills, with a documented length-based score. Word Search is untimed: find every word in an 8×8 grid at your own pace. The choice is pressure, not quality: one rewards flow, the other rewards scanning.

## What each game does

| | Word Tile Rush | Word Search |
|---|---|---|
| Grid | Rising letter tiles, you spell adjacent paths | Static 8×8 letter grid |
| Timer | Yes — tile rise interval; starts with your first letter | No |
| Scoring | Documented length-based points, best score local | Solved count and last list local |
| End condition | Grid fills or you submit the last word | All listed words found |
| Keyboard | Select tiles with focus, Submit to score | Arrow cursor + Enter to select cells |
| Typical session | 3–8 min | 5–15 min |

## When to pick each

- **Word Tile Rush** suits a short, focused burst where a timer is part of the fun. Its guide states the rise interval honestly; NoCharge does not claim the timing is "training".
- **Word Search** suits a break where scanning at your own pace beats a countdown. It has no score pressure at all.
- Both are no-account and keep results in `localStorage`; both have documented keyboard paths.

## What NoCharge is not claiming

Neither game is claimed to improve vocabulary, spelling, or attention. "Timed" and "untimed" describe mechanics, not benefits. The [untimed collection](/collections/untimed-or-reduced-pressure-browser-games/) lists the games without a countdown, and the [word games collection](/collections/word-games/) lists both with their exact rules.
