**Bottom line:** Memory Match counts moves, not seconds. Each two-card attempt is one move, and your best (lowest) completed run is saved locally. Timed memory games reward speed; this one rewards a repeatable scan. Neither mechanism is claimed to train memory.

## Mechanism contrast

| | NoCharge Memory Match | Typical timed memory |
|---|---|---|
| Metric | Fewest moves to match 8 pairs | Fastest completion time |
| Clock | None (recorded only after a win, never during play) | Countdown or timer visible |
| Strategy it favors | Systematic board scanning | Quick reaction and luck |
| Persistence | `nocharge:memory-match:best-moves` | Time or score, per game |

## What "good" means here

The article and guide say plainly: a perfect run would be eight moves (one per pair) only if you knew the layout in advance. Ordinary improvement means beating your own best by one or two moves as your scan becomes repeatable. NoCharge does not publish targets, percentiles, or "competition averages".

## Why move-count is the calm metric

- Pausing to think costs nothing.
- A mismatch is information, not a penalty.
- The metric rewards a strategy you can describe — scan order, location labels, immediate known matches — rather than a speed you cannot.

## Limits

Move counting does not make the game easier or "better for memory training". NoCharge makes no cognitive claim for Memory Match or timed alternatives; the mechanism is the distinction, not the benefit.
