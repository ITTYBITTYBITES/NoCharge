> **Bottom line:** Compare Color Flip’s calm tap-to-step board with its untimed Cycle color and Step forward mode.

Color Flip has two unhurried ways to match four labeled colors. Visual mode is a 5×5 tap-to-step board. Turn-based mode presents the next tile as text and retains its fixed Cycle color plus Step forward flow.

Try both on [Color Flip](/games/color-flip/), and see the [Color Flip guide](/guides/color-flip/) for the full controls.

## Visual mode: choose, then step

Start a visual round by choosing Green, Blue, Amber, or Rose. The player sits in the center of the board. Select an adjacent tile with a tap or the arrow keys. A matching tile scores and lets the round continue; a nonmatching tile ends the round.

The board does not move and there is no timer. Each tile and the player include a letter—G, B, A, or R—alongside color. Undo can reverse the most recent step. Rotation can remain Never or change color after every 10 or every 5 successful steps.

## Turn-based mode: cycle, then check

Select **Turn-based mode** to use the existing text-first flow. It tells you the current color and next tile. **Cycle color** advances Green → Blue → Amber → Rose → Green; **Step forward** checks whether the current color matches the announced tile.

A match adds one point and announces a new tile. A mismatch ends that run and moves focus to **Play again**. This mode has no board, movement, or deadline.

## Choose the interaction that feels clearest

Visual mode is for spatial choices on a labeled board. Turn-based mode is for a single announced choice at a time. Both are keyboard-operable, have no timer, and preserve their own local best score.

Pause leaves a visual board or turn-based announcement unchanged. It does not take a step, rotate a color, or generate a new target. For the fixed turn-based order, read [Understanding the four-color cycle](/articles/understanding-the-four-color-cycle/).
